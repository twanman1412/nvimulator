Nvimulator brings (Neo)vim-style modal editing to jEdit. It is a fork of Niels Mündler's port of mike dillon's jEdit plugin Vimulator, maintained separately.
Features
  • a Vim-style command engine: counts, operators (d c y > < = g~ gu gU), motions and text objects
  • insert, replace and the three visual modes (visual, visual line, visual block)
  • repeat with ., search with / ? n N * #, marks, scrolling
  • ex commands, including :[range]s/pattern/replacement/ with Vim regex syntax
  • multiple caret editing

Feedback and contributions are highly appreciated.
